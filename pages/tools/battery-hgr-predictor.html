MODEL DEVELOPMENT

From Experimental Data to Compact Correlation

The analytical correlations were obtained through a multi-stage modelling framework.

01

Experimental HGR

Heat generation data were experimentally obtained using isothermal battery calorimetry under controlled operating conditions.

02

Machine Learning

Machine-learning models were trained using current, C-rate, DOD and temperature as input variables.

03

Polynomial Regression

The selected ML model was approximated using a high-order polynomial representation.

04

Symbolic Regression

PySR was used to obtain a compact analytical expression with substantially fewer terms.
